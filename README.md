# Bergstation Tirol

Inoffizielle Web-App für Wetterstationen und Lawinenreport in Tirol, Südtirol und Trentino.

- Stationen mit Suche, Favoriten, "In der Nähe" und Verlaufsdiagrammen
- Karte mit Messwerten
- Lawinenreport (CAAML v6)
- Hangneigung, Kompass, GPS-Höhe

Daten: Lawinenwarndienste Tirol, Südtirol und Trentino über https://lawinen.report.
Maßgeblich ist immer der offizielle Lawinenreport.

Die App ist eine einzelne Datei (`index.html`) ohne Build-Schritt.
